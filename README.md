# GenAI Project

A Python-based Generative AI and Machine Learning project.

## Project Overview

This project explores machine learning, synthetic financial transaction data, fraud detection, and AI-generated analysis.

## Technologies
- Python
- Pandas
- NumPy
- Machine Learning
- Anthropic API integration

## Project Structure
- scripts/ - Python source code
- reports/ - Analysis reports and visualizations
- data/ - Local datasets
- models/ - Trained machine learning models

## Features
- Synthetic data generation
- Machine learning model training
- Fraud risk analysis
- Model evaluation and visualization
- AI-generated explanations

## Notes
The project uses synthetic financial transaction data.
Local datasets and trained models are excluded from GitHub.
